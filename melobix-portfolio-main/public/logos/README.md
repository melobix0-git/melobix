# Project logos

Drop one image per project here (e.g. `trova.png`, `yimba.svg`, `tickr.png`)
and reference it from `src/data/projects.ts`:

```ts
{
  title: "Trova",
  logo: "/logos/trova.png",
  /* ... */
}
```

Until a `logo` is set, each project card renders a dashed placeholder with the
project's initial.
